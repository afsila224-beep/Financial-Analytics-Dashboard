Financial-Analytics-Dashboard
An interactive Financial Performance Dashboard built using Microsoft Power BI and the Global Superstore dataset. It analyzes sales, profit, discounts, and units sold through KPI cards, interactive slicers, and visual charts. The dashboard provides insights into product performance, customer segments, country-wise sales, and monthly trends. 
 Financial Performance Dashboard | Power BI

 📊 Project Overview

The Financial Performance Dashboard is an interactive Power BI project developed to analyze business sales, profitability, discounts, and product performance. It transforms financial data into meaningful insights using interactive visualizations, KPI cards, slicers, and bookmarks.

 🖥️ Dashboard Preview

![Financial Performance Dashboard](images/financial-dashboard.png)

🎯 Objectives

- Analyze overall sales and profit performance.
- Evaluate country-wise sales distribution.
- Identify top-performing products.
- Understand sales contribution by business segments.
- Analyze monthly units sold trends.
- Explore financial performance using interactive filters.

 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and visualization.
- **Microsoft Excel** – Dataset management and preparation.
- **DAX** – Measures and KPI calculations.

 📁 Dataset

The Financial Sample dataset contains:

- Sales and Gross Sales
- Profit and COGS
- Discounts
- Units Sold
- Manufacturing Price
- Sale Price
- Product and Segment
- Country
- Date, Month Number and Month Name
- Discount Band

 📈 Dashboard Features

 1. Key Performance Indicators (KPIs)

- Total Sales: 118.73M
- Total Units Sold: 1.13M
- Total Profit: 16.89M
- Total Discounts: 9.21M

 2. Data Visualizations

- **Sales by Segment:** Analyzes sales contribution across different business segments.
- **Sales by Country:** Compares sales performance across countries.
- **Sales by Products:** Identifies product-wise sales performance.
- **Geographical Sales Distribution:** Displays sales distribution across different geographical locations.
- **Monthly Units Sold Trend:** Shows monthly changes in units sold.

 3. Interactive Features

- Product slicer
- Country slicer
- Segment slicer
- Discount Band slicer
- Bookmark navigation buttons:
  - Overview
  - Sales Analysis
  - France View

 🔍 Key Insights

- Total sales reached 118.73M.
- Total profit was 16.89M.
- Total units sold reached 1.13M.
- Total discounts amounted to 9.21M.
- The dashboard allows comparison of sales across countries, products, and business segments.
- Monthly trend analysis helps explore changes in units sold.
